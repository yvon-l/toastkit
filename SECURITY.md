# Security

ToastKit runs entirely in your browser. It has no server, no account and no telemetry.

## Reporting a problem

Please don't open a public issue for a security or privacy problem. Use GitHub's private reporting instead:

https://github.com/yvon-l/toastkit/security/advisories/new

Include the ToastKit version, your browser version, what you did, and what happened.

## What counts

- Clearing data for a site other than the one you chose
- Anything that sends data off your device
- Untrusted page content rendered in the popup
- Permissions broader than the extension needs

## Supported versions

Only the current releases on the Chrome Web Store and Firefox Add-ons get fixes. Fixes land on `main` and ship as a patch release.

What ToastKit stores, and why, is described at https://kimberly-wood.com/privacy/#browser-extensions
